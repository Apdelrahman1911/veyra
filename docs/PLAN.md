- Single authoritative session/coordinator with independent music/podcast queue contexts and managed native decks; media controls/background/interruption/route handling. Required music-only equal-power crossfade, persistent enable/disable and 2/3/4/5-second settings, safe interruptions, automated tests and physical-device audio verification.
- Complete normalized Room schema with transactions, safe versioned migrations, concurrency/recovery tests; central full-title/first-result kmpYT resolution for all playable content, pinned reproducibly; meaningful tests; clean-checkout instructions; per-target artifacts and honest platform/signing verification matrix.
- Typed aggregate acquisition (D010): genuine album/release metadata producer; actual first-result Single/Collection/Unplayable resolution; complete resolved-source occurrence traversal preserving holes/duplicates/partial scope; neutral recording identity and explicit controls mode; immutable normalized request/receipt/member/queue/history lineage; durable collection batches over the existing leased download engine. Safe migrations must not invent historical provenance.

Local audio references/import must also respect central kmpYT execution and may not substitute for real streaming; no independent media-acquisition engine. Optional only after essentials: recommendation personalization, extensive EQ/audio effects, cloud sync/accounts, desktop Linux ARM64, large-scale catalog indexing, automatic feed scheduling, sample-accurate gapless beyond required crossfade, transcripts, and elaborate animation.

## Final product and architecture direction
- Four destinations: **Listen, Search, Podcasts, Library**. Listen is cross-media continuation plus clearly attributed discovery; Search handles explicit catalog/local scopes; Podcasts owns Continue/New/Following/show details/Add RSS; Library owns saved items, playlists, favorites and downloads. Settings is a secondary destination. See the research reports for screen concepts and source-linked reasoning.
- Original Quiet Currents design: petrol/sea-glass/sand, paired light/dark themes, bundled IBM Plex Sans Arabic with OFL notices, 48dp targets, content-sized rows and adaptive bottom bar/rail/sidebar. Mirror navigation, not media transport/time. Localized errors are part of the shared resource contract.
- One app-lifetime coordinator/session with managed native decks with **two persistent queue contexts** (Music/Podcast). Viewing a context never activates audio. Restore paused. Position samples come from the native engine; generation/seek tokens reject stale callbacks. Explicit collection replacement preserves recoverability; manual queue reorder disables shuffle visibly without dropping occurrences.
- Podcast completion uses confirmed natural end or an explicit mark action, independent of saved progress/downloads. Default speed 1x; initial verified range 0.5–2x; configurable back15/forward30. Duration sleep timers follow the active session in wall-clock elapsed time and remain visible across contexts; end-episode timers bind to the selected episode and stop before queue advance.
- `:shared` owns domain/data/source/download/playback contracts and implementations; `:composeApp` owns shared Compose UI and platform engines/hosts; `iosApp` is the Xcode host. Constructor injection and a single AppContainer, not per-screen clients or players.
- Kotlin2.2.21/Compose1.9.3/AGP8.13.2/Gradle8.13/JDK21, JVM17 bytecode; pin upstream as a Git submodule. AGP is outside KGP's published fully tested range, so actual build gates are mandatory. Room2.8.5/SQLite2.6.2/KSP2.2.21-2.0.4 provide normalized entities/relations, exported schemas, safe migrations, transactionally consistent queue/history/progress/download/settings state and crash reconciliation. `AppSnapshot` is an in-memory UI projection only. No JSON snapshot database, destructive reset or silent in-memory fallback.
- Native transports: Android Media3; iOS AVPlayer; desktop raw libmpv C API through JNA using pinned per-host native runtime artifacts. Native session commands route back to the same coordinator. All media-file work streams; no whole-audio in-memory buffering.
- kmpYT is the sole central media execution library: discover complete metadata, search the **complete title**, accept the **first ordered result**, and execute its playback plan/download. RSS/Apple directory/Commons supply discovery only. Preserve requested and resolved provenance and display recording differences. Do not truncate, filter to later results, open RSS audio independently, bypass authorization or substitute fixture/open media for denied central media. Audit/extend tracks, albums/releases, shows and episode capabilities upstream.
- Downloads are complete persisted Room state machines with attempts/leases, bounded parallelism, checkpoints/renewal/retry, pause/resume/cancel and native background orchestration. kmpYT performs all transfers; Veyra validates/stages/finalizes/reconciles atomically with Room. Real response integrity, format validation and local hash gate Ready; external metadata sizes are advisory. Offline resolution validates local files before any remote resolution; offline mode blocks artwork/catalog/feed/source traffic too.
- Music crossfade uses two deliberately coordinated native streams with equal-power envelopes, headroom protection, persisted 2/3/4/5-second/custom settings and interruption/seek/queue-safe lifecycle. Never automatically crossfade podcasts; physical audible verification is required, not inferred from a null sink.
- Free standard public GitHub Actions runners only; no larger runners, purchases or artifact-storage assumptions. Use logs/job summaries and public Release assets for outputs, with software redistribution/license gates satisfied first. Target Android API23+, iOS16+, Windows10 x64, macOS13+ (arm64/x64), Linux Ubuntu24.04+ x64; architecture variants outside these are optional, not silently claimed.

## Reviewable acceptance groups
1. **Real integration:** discover full metadata; submit complete title to actual kmpYT search and accept its first result (not the first surviving video); inspect its compatible plan; actual app engine advances/pause/resumes/seeks; download final validated file; terminate/restart with native network egress denied and play/seek locally. Preserve requested/resolved provenance. Record YouTube refusals and non-playable first results separately; direct external audio is not a compliant substitute. Repeat supported real path on every executable target; missing essential evidence remains a gap.
2. **Local data/queue:** favorite/save/download/playlist independent; restart retains queue/positions/settings/follows; stale callbacks cannot replace current audio; repeat/shuffle/next/add/move/remove/undo and two-context switches pass deterministic tests. Room schema/foreign keys/unique constraints/transactions, version migrations, concurrent writers and killed-process recovery are tested on each target.
3. **Podcasts:** real Arabic/English feeds; stable GUID identity; no destructive refresh; followed shows and unfinished episodes remain offline; confirmed seek/progress persists; explicit played flags, speed/skips and both timer policies pass fake-clock/native tests.
4. **Reliability/security:** malformed/oversized/hostile feeds, unsafe URLs/redirects, cancellation/ranges/changed validators/HTTP errors/storage failure/corrupt or missing files have truthful recovery; never Ready on partial/undecodable bytes; no signed URLs/secrets in persisted Room metadata/logs (short-lived sensitive transfer state remains private, bounded and cleaned).
5. **Crossfade:** tests cover equal-power envelopes, configured timing, enabled/disabled/duration changes, short/unknown tracks, seeking, queue changes and interruptions; actual music overlap and no podcast alteration are checked through physical native audio output on each platform. No hardware means an unmet gate.
6. **UX/platform:** every core state in en/ar/light/dark; phone/desktop screenshots reviewed at narrow/wide/large text; keyboard/back/focus/labels tested; singleton audio/session and background/interruption/routes tested where hardware/environment supports, explicitly matrixed otherwise.
7. **Delivery:** final-revision tests/builds, clean checkout/setup, bundled runtime closure and source notices, per-target installable or unsigned/signing-limited artifacts and exact links. No essential feature is reclassified as optional to finish.
